# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Construir um jogo da forca em Python usando strings, loops, condicionais e entrada de dados do usuário para praticar lógica de programação e manipulação de textos.

## 📝 Tarefas

### 🛠️ Criar o gameplay do jogo

#### Descrição
Crie um jogo da forca em que o programa escolhe aleatoriamente uma palavra de uma lista predefinida e permite que o jogador tente adivinhar letras até descobrir a palavra ou esgotar as tentativas.

#### Requisitos
O programa concluído deve:

- Selecionar uma palavra aleatória de uma lista de palavras pré-definida pelo programador.
- Mostrar a palavra oculta com espaços ou underscores no formato, por exemplo: `_ _ _ _ _`.
- Permitir que o usuário insira uma letra por vez.
- Verificar se a letra informada está presente na palavra.
- Atualizar a visualização da palavra conforme as letras corretas forem descobertas.
- Registrar e exibir o número de tentativas restantes.
- Encerrar o jogo quando o usuário acertar a palavra ou quando as tentativas acabarem.
- Exibir mensagens de vitória e derrota de forma clara.

### 🛠️ Melhorar a experiência do usuário

#### Descrição
Ajuste a interface do jogo para tornar a experiência mais amigável, com feedbacks claros e funcionamento mais fluido durante a partida.

#### Requisitos
O programa concluído deve:

- Validar entradas do usuário para evitar letras inválidas ou entradas vazias.
- Informar ao jogador quando a letra já foi tentada antes.
- Exibir uma mensagem de confirmação quando a letra estiver correta ou incorreta.
- Mostrar o progresso da palavra a cada tentativa.
- Encerrar a partida com uma mensagem final informando se o jogador venceu ou perdeu.
- Utilizar estruturas de repetição e condicionais para controlar o fluxo do jogo.
